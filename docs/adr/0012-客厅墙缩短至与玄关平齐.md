# 客厅墙缩短至与玄关平齐

ADR-0010 把客厅墙做满到东侧外墙、并在靠玄关一端留 1.2 米门洞，目的是让大门到沙发有一条直接通路。业主要求改为：客厅墙延伸到正门所在的东侧外墙（南端不变），但北端从公共区北边界（y 方向 3.5 米轴线起点）收短到与玄关北边界取平——墙长正好等于玄关进深 2.57 米，中间不再开门洞。

这个改动把客厅与玄关之间原来的门洞封死，同时把原来墙体覆盖的"茶座区与客厅之间"（2.3 米宽）改为敞开。结果是客厅不再直接连通玄关，进客厅固定路线为：玄关直行进茶座区，再向右转经 2.3 米敞口入客厅。客厅内的沙发、茶几和电视矮柜整体随之从原来靠近开放过厅一侧（北段）挪到靠近玄关、正门一侧（南段），北墙对应的高窗也一并南移；电视矮柜长度受墙体缩短影响，由 2.7 米收至 2.3 米。

结构上的代价：ADR-0010 原本借这堵墙把 7.5 米的南北向大跨一分为二，现在墙体缩短后，玄关＋茶座区＋过厅一侧恢复为约 7.46 米的连续无柱跨度，客厅本身则是 4.87 米跨度，均比墙做满时更大，梁跨和屋面支承方式必须由结构专业人员重新核实，必要时在茶座区／客厅敞口处增设梁下柱。
