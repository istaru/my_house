# 过厅茶座玄关合并为堂屋

第二版把公共区南侧一条 3.5 米宽的带子分成三个命名空间：开放过厅 3.5×2.6＝9.1 平方米、茶座区 3.5×2.30＝8.1 平方米、玄关 3.5×2.57＝9.0 平方米，三者之间只有软分界，没有实墙。业主指出这三块加起来 26.2 平方米，占全屋 121.64 平方米的 21.5%，是全屋最"虚"的一块，要求先把它们合成一个区域。

三者同宽 3.5 米，进深 2.6＋2.30＋2.57＝7.47 米，本来就是一条完整矩形，合并不需要移动任何墙体。合并后命名为**堂屋**，3.5×7.47＝26.2 平方米，从东墙正门一路贯通到西侧卧室 4（原书房）门口。

这个决定推翻了 CONTEXT.md 中"开放中厅"条目原有的 `_Avoid_: 堂屋、中央走廊、贯通大厅`。当初回避"堂屋"是为了摆脱参考图的中轴对称格局（见 ADR-0004、ADR-0005），但本方案的堂屋是偏置的、不对称的、三面接房间一面接开放厅的功能带，与参考图的中轴堂屋在几何上没有关系，只是沿用了业主熟悉的名称。

随之确定的做法：

- 地面、吊顶、踢脚一次做通，中间不设过门石、不做吊顶跌级、不做地面分色，否则合并没有意义。
- 一个空间保留三段用途：东段约 2.57 米入户、中段约 2.30 米待客、西段约 2.60 米过渡，只靠家具和照明区分。
- 南侧通长柜做 4.87 米，东端鞋柜、中段茶具柜，收纳量超过第二版分段布置。（初稿误写为 7.47 米整条：堂屋南侧西段 2.6 米实际是短廊的敞开通行口，不是实墙，做不了柜，复核时已更正。）
- 堂屋没有外窗（正门两侧的侧窗已按 ADR-0017 取消），全靠北侧敞口向客餐一体厅借光，西段（靠卧室 4 那头）最暗，需要人工照明补充，或另行研究天窗。
