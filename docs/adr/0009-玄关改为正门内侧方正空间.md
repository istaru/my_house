# 玄关改为正门内侧方正空间

业主指出原布局"开门左手是储藏间、右手才标玄关"讲不通。原因是当时把玄关画成贴东墙、进深只有 1.26 米、长 7.5 米的条带，进门站的位置其实是过道而不是玄关，储藏间的门又正好开在这条过道上。

改为把玄关做成正门内侧 3.5×2.57 米、共 9.0 平方米的方正空间：进门就站在玄关里，正前方是茶座区，左手是储藏间门和鞋柜位，右手是 2.57 米宽的通口直接进客厅。让出的东墙北段并入客厅，客厅因此同时占北墙和东墙，由 14.4 平方米增加到 19.5 平方米，并获得东墙落地窗这一主要采光面；茶座区相应由 12.6 平方米收到 8.1 平方米，电视背景墙由 2.63 米改为 2.30 米、南端与玄关北边界齐平。开放区总面积 56.0 平方米不变。

同时更正 ADR-0008 中"进门看不到沙发坐区"的说法：电视背景墙与入户方向平行，挡不住从正门斜看沙发区的视线，它只是电视背景墙，不是入户屏风；若确需遮挡，应在玄关内另加活动屏风或高柜。
