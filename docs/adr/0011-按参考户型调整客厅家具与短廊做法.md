# 按参考户型调整客厅家具与短廊做法

参照业主提供的商品房户型参考图，采纳三条做法。

第一，客厅沙发由单排 2.4 米靠墙改为 3＋1＋1 围合式：三人沙发仍靠北侧外墙，两端各放一个单人位相对而坐，中间放 1.2×0.6 米茶几。实际坐位由 3 个增加到 5—7 个，适合农村待客的人数。因茶几和单人位占去部分进深，落座点到电视柜面由 3.1 米收到 2.7 米，电视规格相应由 65—75 英寸调整为 55—65 英寸。

第二，电视墙由 1.5 米电视柜改为沿客厅墙北面做满的通长矮柜（当时墙长 4.87 米，受 1.2 米门洞限制做到 2.7 米；ADR-0012 把墙缩短到 2.57 米后矮柜相应收至 2.3 米）。矮柜的储物量大致相当于并入主卧的那间 4.4 平方米储藏间，用于弥补收纳缺口。

第三，两卧室与卫生间之间的 1.05 米开放短廊，装修上按公共区做法处理：地面、踢脚和吊顶与开放过厅一致，两端不做门套、不设门扇。参考图中同样位置（卫生间比卧室浅所留下的边角）就是大厅的一部分，不作为走廊出现。

未采纳参考图的两点：其中央大厅超过 30 平方米且四面无窗，是纯暗厅，本方案的过厅、玄关和茶座区均有直接采光或双侧借光，不为追求大厅尺度让出窗；参考图卫生间设浴缸，本方案为柴火灶住宅，热水供应有限，维持淋浴、蹲便、洗手盆和洗衣机位的配置。
