# 储藏间并入主卧并把客厅墙做到东墙

按业主要求取消东南角的独立储藏间，把这 4.4 平方米直接并进卧室 2，卧室 2 成为 3.5×4.87 米、17.0 平方米的主卧，并因此同时拥有南墙两扇窗和东墙一扇窗；玄关左手由储藏间的门变成主卧的整面实墙，可以整墙做鞋柜。代价是三个房间不再等大，卧室 1 和书房保持 12.6 平方米，主卧比它们大 4.4 平方米。

同时把电视背景墙由 2.30 米延长到 4.87 米、直抵东侧外墙，改称客厅墙，客厅由此成为一间有明确边界的房间。为避免从大门到沙发必须经茶座区、过厅、餐厅绕行约 12 米，在客厅墙靠玄关一端留 1.2 米门洞；客厅另有北侧 4.0 米敞口直通六人餐厅。公共空间总量 56.1 平方米不变，但不再是一整块连续开放区，而是"玄关＋茶座区＋过厅＋餐厅"约 36.6 平方米加上 19.5 平方米的客厅。

附带的结构好处：这堵墙把原来 7.5 米的南北向无柱大跨一分为二，剩余最大跨度约 3.5 米。
