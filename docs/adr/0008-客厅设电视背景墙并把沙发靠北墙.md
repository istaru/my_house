# 客厅设电视背景墙并把沙发靠北墙

沙发靠北侧外墙布置，坐向朝南，因此电视必须挂在与北墙平行的面上。开放区内原本没有这样一面墙，故在南北向 3.5 米轴线上加一堵长 2.63 米的室内隔断作为电视背景墙，东端留 0.97 米通道。该轴线与书房和厨房之间的隔墙、餐厅和过厅之间的分界在同一条线上，平面不产生新的转折。

这堵墙同时承担入户屏风的作用：南面朝向东侧正门，进门看不到沙发坐区。代价是原本 27.0 平方米的连续客厅被分成 14.4 平方米沙发区和 12.6 平方米茶座区，但两者通过墙东端通道、玄关区和过厅三条路相连，开放区总面积 56.0 平方米不变。沙发遮挡北墙落地窗，故该处改为窗台约 1.1 米的高窗。墙体不承重；若结构复核要求在开放区落柱，柱子应并入这堵墙。
