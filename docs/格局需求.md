# 民居格局需求

## 当前范围

- 建筑状态：尚未开工，当前只建设一层，基础和主体结构只按一层设计。
- 建筑面积：保持 121.64 平方米。
- 建筑轮廓：整体采用完整方正主体，任何封闭房间均不得凸出外轮廓。
- 方位约定：页面上方为西、右侧为北、下方为东、左侧为南。
- 房间配置：两间卧室、一间书房、一个完整卫生间、一间柴火厨房、一个六人餐厅、一个客厅和一个玄关。
- 房间面积：卧室 1 和书房为 3.5×3.6 米、各 12.6 平方米；卧室 2 为 3.5×4.87 米、17.0 平方米的主卧。
- 公共空间：玄关、茶座区、过厅和餐厅开放连接，餐厅不设隔墙；客厅墙从正门一侧东墙延伸到与玄关平齐、不开门洞，客厅改由茶座区一侧的 2.3 米敞口进入。不设置贯穿式走廊。
- 卫生间：设置淋浴、蹲便器、洗手盆和洗衣机位，预留未来改装坐便器的条件。
- 厨房：只保留柴火灶，同时配置水槽、冰箱、连续操作台、独立排烟和东墙角后门。
- 出入口：东墙中部设置正门，厨房后门位于东墙角；东侧前院保留两辆汽车的位置。
- 外窗：每个房间同一面墙只设置一扇窗，窗位按对应房间墙段中部布置。
- 最终出图：概念方案确认后，使用 AutoCAD＋天正建筑或兼容建筑 CAD 绘制正式平面图，按 1:100 输出 DWG 和 PDF；正式图纸需包含轴网、墙厚、门窗编号与尺寸、房间名称、标高、建筑面积和图框。
- 风格：立面和室内采用现代简约，屋顶保留高坡小青瓦、翘角和脊饰样式。
- 室内顶面：采用平吊顶，普通房间净高约 3.0 米，开放中厅约 3.2 米。

## 布局参照

- 西侧一排由南向北布置卧室、书房和厨房。
- 南侧一带由西向东布置卧室、卫生间＋开放短廊和作为主卧的第二间卧室。
- 中央及东侧形成公共区，内含玄关、茶座区、开放过厅和六人餐厅；东北角由客厅墙围出客厅，餐厅紧邻厨房门。
