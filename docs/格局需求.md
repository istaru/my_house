# 民居格局需求

## 当前范围

- 建筑状态：尚未开工，当前只建设一层，基础和主体结构只按一层设计。
- 建筑面积：保持 121.64 平方米。
- 建筑轮廓：整体采用完整方正主体，任何封闭房间均不得凸出外轮廓。
- 方位约定：页面上方为西、右侧为北、下方为东、左侧为南。
- 房间配置：两间卧室、一间书房、一个完整卫生间、一间柴火厨房、一个六人餐厅、一个客厅和一个玄关。
- 公共空间：玄关、客厅和餐厅采用参考图所示的开放连接方式，不设置贯穿式走廊。
- 卫生间：设置淋浴、蹲便器、洗手盆和洗衣机位，预留未来改装坐便器的条件。
- 厨房：只保留柴火灶，同时配置水槽、冰箱、连续操作台、独立排烟和北侧后门。
- 出入口：东侧设置正门，北侧厨房设置后门；东侧前院保留两辆汽车的位置。
- 风格：立面和室内采用现代简约，屋顶保留高坡小青瓦、翘角和脊饰样式。
- 室内顶面：采用平吊顶，普通房间净高约 3.0 米，开放中厅约 3.2 米。
