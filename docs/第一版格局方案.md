# 第一版格局方案

> 本方案是用于确定房间关系、朝向和动线的概念平面，不是施工图。墙厚、门窗结构尺寸、屋面受力、排烟、防火和最终建筑面积必须由有资质的建筑及结构专业人员复核。

## 总体布局

主体暂按南北长 14.3 米、东西宽 8.5 米的近矩形布置，外轮廓面积约 121.55 平方米。最终可在不改变格局逻辑的前提下微调约 0.09 平方米，使报建建筑面积与 121.64 平方米一致。

- **南端**：老人房和客厅共同占用最好的南向短边；东侧前门进入客厅旁的小玄关。
- **西侧卧室带**：完整公卫、两间条件相近的夫妻房和成年人房依次向北布置，全部直接开西窗。
- **东侧功能带**：六人餐厅、柴火厨房和多功能房依次向北布置，均可直接开东窗。
- **北端家务区**：简配公卫、独立洗衣区和家务后门集中布置，后门外连接储柴与晾晒区。
- **中央交通带**：使用约 1.2 米宽的短直走廊连接卧室和家务空间，所有卧室门及卫生间门避开客餐厅和前门视线。

## 空间草案

| 空间 | 概念轴线尺寸 | 布置说明 |
| --- | --- | --- |
| 老人房 | 约 3.5×3.6 米 | 南向，靠近完整公卫，使用 1.5×2.0 米床 |
| 夫妻房 A | 约 3.25×3.6 米 | 西向，使用 1.8×2.0 米床和整墙衣柜 |
| 夫妻房 B | 约 3.25×3.6 米 | 与夫妻房 A 同朝向、同尺度 |
| 成年人房 | 约 2.9×3.6 米 | 西向，使用 1.5×2.0 米床 |
| 多功能房 | 约 2.2×3.7 米 | 东向，前期书房、未来儿童房 |
| 客厅＋餐厅 | 合计约 24 平方米轴线面积 | 南向客厅与东向餐厅开放连接，入口设鞋柜或屏风 |
| 柴火厨房 | 约 3.5×3.7 米 | 双灶眼、水槽、冰箱和连续操作台，实体门隔烟 |
| 完整公卫 | 约 1.4×3.6 米 | 淋浴、蹲便、洗手盆，预留未来坐便改装条件 |
| 简配公卫 | 约 1.3×2.7 米 | 蹲便和洗手盆，从家务前室进入 |
| 洗衣区 | 约 1.0×2.7 米 | 室内洗衣，靠北侧后门，室外晾晒 |

尺寸是建筑轴线或功能分格的概念值，不等同于完成面净尺寸。墙体加入后，夫妻房、多功能房和厨房的实际净面积会略低于访谈中的目标值，施工图阶段需要通过墙厚和局部尺寸微调恢复使用舒适度。

## 动线

```text
东侧前院 → 前门/玄关 → 客厅 → 餐厅 → 柴火厨房
                           ↓
                        中央走廊 → 四间卧室 / 多功能房 / 两个公卫
                           ↓
                     北侧家务后门 → 储柴 / 晾晒
```

- 来客活动集中在客餐厅，不穿过卧室区。
- 老人房到完整公卫只需经过南端过厅，不经过客餐厅。
- 柴火从北侧家务后门进入，经短走廊抵达厨房，不经过客厅。
- 洗衣、晾晒、储柴和简配公卫集中在北端，减少对南侧采光面的占用。

## 采光与通风

- 老人房和客厅直接朝南开窗。
- 两间夫妻房及成年人房直接朝西开窗，使用外遮阳或较深屋檐控制西晒。
- 餐厅、柴火厨房、多功能房、简配公卫和洗衣区直接朝东开窗。
- 客餐厅具有南、东两个方向的开窗条件；中央走廊通过东侧前门和北侧后门形成通风路径。

## 屋顶与结构边界

- 平面只控制近矩形建筑主体，不规定屋面的数量和交叉形状。
- 屋顶外观必须采用已确认的高坡小青瓦、翘角屋脊和中央脊饰样式。
- 室内使用平吊顶；普通房间净高约 3.0 米，客餐厅约 3.2 米。
- 基础和主体结构只按一层设计，文件不承诺未来能够安全加层。
