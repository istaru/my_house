# 第二版方正两卧开放中厅格局方案

> 本方案按最新参考图重绘，只保留两间卧室、一间书房、一个卫生间、厨房、餐厅、客厅和玄关。它是概念平面，不是施工图。

## 总体尺寸

主体暂按南北长 11.00 米、东西宽 11.058 米控制，外轮廓面积约 121.64 平方米。所有封闭房间都位于同一个完整方框内，不保留参考图中向外凸出的卧室、卫生间或厨房附属空间。

## 房间关系

- 西侧第一排由南向北依次为卧室 1、书房、六人餐厅和柴火厨房。
- 南侧由西向东依次为卧室 1、完整卫生间和卧室 2。
- 卫生间没有占满南侧进深，右侧设置一条直接连通开放中厅的开放短廊。两间卧室和卫生间各自从短廊进入。
- 中央与东侧形成连续开放空间，靠南布置玄关，靠北布置客厅，餐厅位于西侧并与客厅开放相连。
- 柴火厨房使用实体门与开放中厅分隔，并在北侧外墙设置后门。

## 概念尺寸

| 空间 | 概念尺寸 | 说明 |
| --- | --- | --- |
| 卧室 1 | 约 3.2×3.6 米 | 南向开窗，房门从开放短廊进入并向卧室内开启 |
| 卧室 2 | 约 3.2×4.57 米 | 南向及东向开窗，房门从开放短廊进入并向卧室内开启 |
| 书房 | 约 2.6×3.6 米 | 西向开窗，直接联系开放中厅 |
| 六人餐厅 | 约 2.4×3.6 米 | 西向采光，与客厅保持开放联系 |
| 柴火厨房 | 约 2.8×3.6 米 | 双灶、水槽、冰箱、操作台和北侧后门 |
| 完整卫生间 | 约 2.3×2.9 米 | 淋浴、蹲便、洗手盆、洗衣机位；门向卫生间内开启 |
| 玄关＋客厅 | 约 39 平方米开放区域 | 东侧正门进入玄关，右侧形成主要客厅区 |

尺寸为外轮廓内的功能分格值，未扣除墙厚。施工图阶段需要优先复核柴火厨房连续操作台、卫生间四件设备和卧室家具通道。

## 动线

```text
东侧前院 → 正门 → 玄关 → 客厅 → 餐厅 → 柴火厨房
                         ├→ 书房
                         └→ 开放短廊 → 卧室 1 / 完整卫生间 / 卧室 2

北侧家务院 → 厨房后门 → 柴火厨房
```

- 入户后视线落在开放客厅，不直接看见卧室床位和卫生间内部。
- 两间卧室与卫生间共用一条约 0.9 米宽的开放短廊，短廊不再设置第四扇门。
- 三扇门全部向各自房间内部开启，走廊内没有门扇交叉或互相碰撞。
- 两间卧室建议采用 900 毫米门洞，卫生间建议采用 800—850 毫米门洞；最终净宽由施工图结合墙厚确定。
- 卧室 2 完全收回方正主体，不再像参考图一样突出外墙。
- 柴火从北侧后门直接进入厨房，不经过客厅。

## 采光与通风

- 两间卧室均直接朝南开窗，卧室 2 还可增加东窗。
- 书房、餐厅和厨房直接朝西开窗。
- 客厅通过东侧正门两侧大窗和北侧窗采光。
- 卫生间位于南侧外墙，可直接开窗排湿。

## 屋顶与结构

- 平面保持完整方正，屋面形状按方正主体重新组织。
- 屋顶继续使用高坡小青瓦、翘角屋脊和中央脊饰样式。
- 基础和主体结构只按一层设计，不承诺未来能够安全加层。
- 施工前必须由建筑及结构专业人员复核墙柱、屋面、排烟、防火和最终建筑面积。
