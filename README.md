# 民居格局重设计

在政府提供的两份农村自建房设计图基础上，重新做一层平面格局。当前采用**第一版 方正四卧等大格局**：建筑面积 121.64 平方米，四间卧室完全等大、各 14.8 平方米，一间完整卫生间，一间柴火厨房，外轮廓完整方正、没有任何房间凸出。

在线预览：<https://istaru.github.io/my_house/>

> 本仓库全部是概念方案文件，**不是施工图**。墙厚、门窗结构尺寸、屋面受力、排烟、防火和最终建筑面积必须由有资质的建筑及结构专业人员复核。

## 方位约定

**页面上方为西、右侧为北、下方为东、左侧为南。** 这是业主按现场实际朝向确认的，不是常规的"上北下南"。所有图纸、文档和讨论一律沿用这一套，任何采光和朝向结论都建立在它之上。

## 最终交付

概念方案确认后，用 AutoCAD＋天正建筑（或兼容的建筑 CAD）绘制正式平面图，按 1:100 输出 DWG 和 PDF。正式图纸需包含轴网、精确墙厚、门窗编号与尺寸、房间名称、标高、建筑面积和完整图框。本仓库的 SVG 只作为格局和样式参考，不作为施工尺寸来源。
